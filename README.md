# 十字回廊 · CROSS//WARD

一个极简风格的横向卷轴塔防小游戏。地图是一个「十」：在红轴的侧视画面中，蓝轴以竖直光束的方式穿过中心。走到中央传送门互动，世界会转 90°，切换到另一条轴。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或构建。

也可以在当前目录启动一个本地服务器：

```powershell
python -m http.server 8765
# 然后打开 http://127.0.0.1:8765/
```

## 操作

| 输入 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移动礼帽角色 |
| `E` | 在中央传送门处转向另一条轴 |
| `P` / `Esc` | 暂停 / 继续 |
| `H` / `?` | 打开玩法说明 |
| `M` | 静音 / 取消静音 |
| `R` | 失败后重新开始 |
| 触屏 | 左右移动按钮 + 「转向」按钮 |

## 规则

- 画面会横向卷轴，中心是共用的传送门核心。
- 红轴、蓝轴各有左右两扇深紫色传送门，共四扇。
- 每扇传送门每 **20 秒** 释放 **2 只史莱姆**，史莱姆生命值为 **1**。
- 黑色礼帽角色自带自动弩箭：**每秒 1 发，伤害 1**，自动锁定当前轴上最靠近核心的敌人。
- 史莱姆碰到中心核心会扣除 1 点核心完整度；核心完整度为 0 时游戏结束。
- 进入另一条轴时，原来的轴仍会继续涌出敌人。右上角 `AXIS MAP`、轴计数与底部警告会提示另一条轴的威胁。
- 分数、最高分和静音设置会保存在 `localStorage` 中。
