# 十字回廊 · CROSS//WARD

一个由黑色、红色、蓝色三种基本几何构成的横向卷轴塔防小游戏。战斗在红色轴上发生；蓝色轴是预留给经济与升级系统的区域。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或构建。

也可以在当前目录启动本地服务器：

```powershell
python -m http.server 8765
# 然后打开 http://127.0.0.1:8765/
```

## 操作

| 输入 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `Space` | 在竖向矩形与横向矩形之间翻转 |
| `E` | 靠近中央黑色裂缝时进入俯视切换 |
| `P` / `Esc` | 暂停 / 继续 |
| `H` / `?` | 打开玩法说明 |
| `M` | 静音 / 取消静音 |
| `R` | 失败后重新开始 |
| 触屏 | 左右移动 + 翻转 + 裂缝切换 |

## 规则

- 横向卷轴画面中的红色轴是战斗平台，中央有一道可互动的黑色裂缝。
- 平台两端各有一扇边缘传送门。非刷怪状态时它们是一条黑色细线；每 **20 秒** 展开为长方形，并从每扇门释放 **2 个纯黑圆形史莱姆**。
- 每个黑色圆形拥有 **3 点生命**。矩形角色顶部的自动弩箭每秒发射 1 次，伤害 1。
- 黑圆抵达中央裂缝会扣除 1 点核心完整度；核心完整度耗尽时游戏结束。
- 按 `Space` 让黑色矩形在竖立与横躺之间翻转，弩箭始终固定在矩形顶面。
- 蓝色轴是经济与升级区域，没有传送门，也不会刷怪。目前放置的是保留的经济节点。
- 在中央裂缝按 `E` 会进入短暂的俯视视角：先显示十字轴布局，再旋转并放大到另一条轴，最后落到目标轴的横向视角。
- 角色进入蓝轴后，红轴仍会继续运行；左上角会提示红轴未处理的敌人数。
- 得分、最高分和静音设置保存在 `localStorage`。

## 文件

- `index.html` — 页面与几何 HUD
- `styles.css` — 排版、响应式布局与覆盖层
- `game.js` — 游戏循环、几何渲染、敌人、弩箭和俯视转场
- `preview.png` — 画面预览
